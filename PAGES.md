## Deploy build — static site at production paths

The 48 design files are now built out as hardcoded HTML at their production paths
(`/index.html`, `/about/index.html`, `/es/nosotros/index.html`, …), one folder per
page, ready for Cloudflare Pages at sunworxcali.com. No copy was changed: the
visible text and every `<title>` / meta description are byte-identical to the
design files.

What the conversion did, and nothing more:

- `<x-dc>` / `<helmet>` unwrapped into a normal `<head>` and `<body>`.
- The Claude Designs reactive runtime (`sc-if`, `{{ }}` bindings, `data-dc-script`)
  replaced by plain markup plus `/js/site.js` — same mobile-nav and Service Areas
  dropdown behaviour, no framework.
- `style-hover` / `style-focus` attributes lifted into real CSS in `/css/site.css`.
  They carry `!important` because the design styles every element inline.
- `<image-slot>` elements replaced by `<img>`, keeping each slot's `object-fit` and
  corner radius. The designed `placeholder` string is preserved on the image as
  `data-placeholder`, and the `REAL JOB PHOTO` / `REAL VIDEO` comments stay put, so
  Sun Worx's own media still drops straight in.
- Language-toggle and logo links, which pointed at the working `.dc.html` files,
  now point at production paths. Every internal link is root-relative with a
  trailing slash.
- Design sources moved to `_design-source/` (the `.dc.html` files, `support.js`,
  `image-slot.js`, `_parts/`) so the served root is clean. Nothing links to them.

Media: the six `pixabay.com/get/...` job-photo URLs had expired (HTTP 400, empty
boxes), so each now points at the Pixabay still already used on the site for the
same subject, in `/img/` — no page repeats an image. Video posters are served from
`/img/` too. The nine hero `.mp4` files stay on the Pixabay CDN because five of them
are larger than Cloudflare Pages' 25 MiB per-file limit. Still Pixabay only, still
no attribution and no visible credit.

Link check: 4,066 references across all 48 pages — internal links, in-page anchors,
images, video posters, the sitemap and the hreflang pairs — all resolve. Zero dead
links. On `/privacy/`, `/thank-you/`, `/es/privacidad/` and `/es/gracias/` the header
and mobile-bar `Get a Free Quote` buttons pointed at `#quote`, which those four pages
deliberately do not have; they now point at the contact page. Button text unchanged.

Still open, deliberately left as placeholders: the quote form endpoint
(`action="#"` plus `<!-- WIRE FORM ENDPOINT IN CODE PHASE -->` on all 44 form pages),
the GA4 tag (`<!-- GA4 TAG IN CODE PHASE -->` on all 48), the Google review URL, the
booking calendar, and the TEMP city-link routing to region hubs. The 31 `og:image`
files the page heads reference (`/img/og-*.webp`, `/img/<region>.jpg`) have never been
produced — social shares will have no preview image until they are.
